BEFORE YOU UPLOAD — HOST AND FOLDER
--------------------------------------------------------------------
Create this folder in the allenberry-assets repo:

    emails/2026-08-06-stay-and-play/

Naming follows your existing GitHub convention (2026-05-13-spring-
renewal, 2026-06-15-fathers-day, 2026-06-29-july4): send date, then a
short slug.

A .gitkeep is included in this zip for creating the folder. NOTE: it is
a dotfile, so macOS Finder hides it after unzipping — if you do not see
it, either press Cmd+Shift+. to reveal hidden files, or skip it and use
the GitHub web UI method below instead.

  GitHub web UI: Add file > Create new file, then type the full path
  into the filename box:
      emails/2026-08-06-stay-and-play/.gitkeep
  Typing the "/" creates the folder. Commit, then upload the images.

Once the images are committed the .gitkeep is redundant — git only
needs it to hold an otherwise-empty directory. Harmless to leave.

Drop the three images below into it. It will serve from:

    https://allenberry-jesse.github.io/allenberry-assets/emails/2026-08-06-stay-and-play/

needed. With this change every image in the send is on the GitHub
